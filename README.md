صفحة الهبوط الترويجية لتطبيق سكنك (Sakanak Landing Page)
​صفحة هبوط (Landing Page) عصرية، احترافية، ومتجاوبة تماماً (Responsive)، مخصصة للترويج لمنصة "سكنك" (المنصة الأولى للبحث عن غرف للإيجار، سكن الطلاب، وشركاء السكن في مصر بدون وسطاء أو سمسار).
​✨ مميزات صفحة الهبوط
​تصميم عصري وجذاب: مُصممة باستخدام أحدث إصدارات Tailwind CSS مع دعم كامل للغة العربية واتجاه النص من اليمين لليسار (dir="rtl").
​إبراز هوية وقيمة التطبيق: تركز على المشاكل التي يحلها التطبيق (الاستغناء عن السماسرة، توثيق الهوية، نظام المطابقة الذكية للطباع).
​محاكاة تفاعلية (App Mockups): عرض شاشات محاكاة لواجهات التطبيق الحقيقية لتعريف الزوار بتجربة الاستخدام قبل التحميل أو التسجيل.
​أقسام متكاملة:
​شريط علوي (Navbar) مع روابط سريعة للأقسام وأزرار العمل المباشر (CTA).
​قسم رئيسي (Hero Section) مع إحصائيات سريعة وأزرار للانتقال للتطبيق.
​قسم مميزات التطبيق (Features) مع أيقونات وتصميم بطاقات بارز.
​خطوات الاستخدام (How It Works): توضيح خطوات إيجاد السكن في 4 خطوات بسيطة.
​جولة بصرية (App Showcase): استعراض ميزات مثل سكن الطالبات والطلاب والشات الآمن.
​آراء المستخدمين (Testimonials): قصص نجاح حقيقية لمستخدمين سابقين.
​الأسئلة الشائعة (FAQ): إجابات على أبرز استفسارات العملاء والمؤجرين.
​متجاوبة بالكامل: تعمل بكفاءة عالية على الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.
​🛠️ التقنيات المستخدمة
​HTML5 (هيكل الصفحة الدلالي).
​Tailwind CSS (CDN) (التنسيق وتصميم واجهات المستخدم).
​FontAwesome 6 (الأيقونات التعبيرية).
​Google Fonts - Cairo (الخط العربي الرسمي).
